# Paranoidal — аудит влияния качества

Сайт: https://expertlove.github.io/paranoidal-quality-audit/

Автономный инструмент для просмотра влияния качества на все предметы модпака Paranoidal (Factorio 2.0.77, ветка `qulity_doc`) и подготовки решений. Решения хранятся в браузере; обмен — кнопкой «Ссылка с решениями» или кодом обмена, итог — JSON/Markdown/CSV на вкладке «Отчёт и обмен».

Данные — статический дамп прототипов; поведение скриптов (брак, потери, мастерская) не моделируется.
